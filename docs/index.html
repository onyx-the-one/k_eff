keff

pronounced like "Jeff", but with a K

keff is a small C program that computes the effective neutron multiplication factor keff by solving the two-group neutron diffusion eigenvalue problem on a one-dimensional slab. The slab is divided into regions, each with its own material, so fuel/reflector sandwiches and axial stacks work. This page documents the mathematics it solves and how to use it.

1. The math

keff is the ratio of neutrons in one fission generation to neutrons in the previous one. If it is below 1 the chain reaction dies away (subcritical), if it equals 1 the reaction sustains itself (critical), and if it is above 1 the reaction grows (supercritical).

The textbook way to write it is the six-factor formula,

k_eff = k_inf * P_F * P_T = eta * epsilon * p * f * P_F * P_T

where eta is the reproduction factor, epsilon the fast fission factor, p the resonance escape probability, f the thermal utilization, and P_F, P_T the fast and thermal non-leakage probabilities. keff does not ask you for these six numbers. Instead it solves the same eigenvalue problem from transport theory directly, in two energy groups:

D1 phi1'' - (Sa1 + S12) phi1 + (chi1/k) S = 0
D2 phi2'' - Sa2 phi2 + S12 phi1 + (chi2/k) S = 0

S = nuSf1 phi1 + nuSf2 phi2

phi1 and phi2 are the fast and thermal scalar fluxes, D the diffusion coefficients, Sa the absorption cross sections, S12 the downscatter cross section (group 1 to group 2), nuSf the nu-times-fission cross sections, and chi the fission spectrum (by default all neutrons are born fast). The eigenvalue k of this system is keff.

2. Numerical method

The slab is discretized with cell-centered finite differences on a uniform mesh. The two coupled equations are relaxed with Gauss-Seidel sweeps at fixed k, and k itself is found by power iteration: normalize the fission source, converge the flux equations, update k from the ratio of new to old source, and repeat until k stops moving. This is the same outer/inner iteration structure used by production nodal codes, just smaller.

Two boundary conditions are available. reflective mirrors the flux at the boundary (no leakage; a homogeneous reflective slab reproduces the infinite-medium k exactly). vacuum forces zero flux at the boundary faces by using an antisymmetric ghost cell, which corresponds to the (pi/W)^2 geometric buckling of a bare slab.

3. Input file

The input is a plain text file with key = value lines. Lines starting with # are comments. Sections are marked with brackets. All lengths are in cm and all cross sections in cm^-1.

The [geometry] section:

keymeaning
widthslab width, cm (required)
meshnumber of mesh cells (required)
boundaryvacuum or reflective (default vacuum)
fluxyes to append the flux profile to the output

A [material name] section, one per material:

keymeaning
d1, d2diffusion coefficients, fast and thermal
sa1, sa2absorption cross sections
s12downscatter cross section
nusf1, nusf2nu times fission cross sections
chi1, chi2fission spectrum, optional, defaults to 1 / 0

The [layout] section has one key, regions, a comma-separated list of material:width pairs, ordered left to right. Example input file:

title = fuel slab with water reflector

[geometry]
width = 100.0
mesh = 200
boundary = vacuum
flux = yes

[material fuel]
d1 = 1.0
sa1 = 0.004
s12 = 0.04
nusf1 = 0.002
d2 = 0.9
sa2 = 0.08
nusf2 = 0.115

[material water]
d1 = 1.1
sa1 = 0.0004
s12 = 0.05
nusf1 = 0.0
d2 = 0.16
sa2 = 0.012
nusf2 = 0.0

[layout]
regions = water:20,fuel:60,water:20

4. Building and running

gcc -Wall -Wextra keff.c -o keff -lm

The -lm matters and must come after the source file: fmax lives in libm and older glibc will not find it otherwise.

./keff -i input.txt            # results to stdout
./keff -i input.txt -o out.txt # results to a file

5. Output

title = fuel slab with water reflector
k_eff = 1.360902
state = supercritical
rho_pcm = +26519.33
outer_iterations = 64

rho_pcm is the reactivity (k-1)/k in units of 10^-5 (pcm). With flux = yes a table of x, phi_fast, phi_thermal follows, each flux normalized to its own maximum.

6. Verification

Two analytic cases check the solver. A homogeneous reflective slab has no leakage, so the result must equal the infinite-medium two-group value 1.022727 for the test constants; the solver returns 1.022727. A bare homogeneous slab with vacuum boundaries must equal the buckling formula [nusf1 + nusf2*S12/(Sa2 + D2*B^2)] / (Sa1 + S12 + D1*B^2) with B^2 = (pi/W)^2, which gives 0.989305 for the same constants; the solver returns 0.989306, the difference being the expected second-order discretization error.
